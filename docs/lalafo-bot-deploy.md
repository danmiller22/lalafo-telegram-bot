# Отдельный бот публикации Lalafo

Для отдельного Koyeb-сервиса используй команду запуска:

```text
python -m app.bot.lalafo_only
```

Сервис использует общую базу данных и группу публикации. Обязательные секреты:

- `TELEGRAM_BOT_TOKEN` — токен отдельного бота из BotFather;
- `ADMIN_USER_ID` — Telegram ID владельца;
- `DATABASE_URL`;
- `CALLBACK_SECRET`.

Дополнительно должны совпадать `TELEGRAM_GROUP_ID`, `TELEGRAM_BOT_USERNAME`,
`LALAFO_PROXY_URL` (если используется) и настройки фильтра.

Сценарий: администратор отправляет ссылку Lalafo в личный чат, бот спрашивает
район, затем публикует карточку в группе. Ограничение повторов для ручной
публикации не применяется.
