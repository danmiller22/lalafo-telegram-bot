# Восстановление сбора Lalafo

Проверка 11 октября 2026: Koyeb и GitHub Actions получают HTTP 403 на публичном
поиске и деталях Lalafo. Обычный Chromium на GitHub Actions также открывает страницу
проверки вместо объявлений. Смена заголовков и официального регионального API не
дала рабочего облачного маршрута. Из отдельного браузерного окружения публичный
каталог открывается: проблема не в отсутствии объявлений.

## Подключение рабочего маршрута

1. Добавить рабочий HTTP- или SOCKS5-прокси с разрешённым доступом к Lalafo в переменную
   `LALAFO_PROXY_URL` сервиса Koyeb и одноимённый GitHub Actions secret.
   Допускается несколько адресов через запятую. Секрет не добавлять в репозиторий.
2. Запустить workflow **Lalafo cloud network check**. Он проверяет настоящий
   поиск и соответствующую карточку; если ни один маршрут не работает, job
   завершается ошибкой. Номера телефонов и адрес прокси в отчёт не выводятся.
3. Проверить `/health`: у `lalafo_inventory.last_collection_result` должны быть
   прочитанные страницы (`search_pages > 0`). `stored` показывает число сохранённых
   кандидатов; в повторном сборе оно может быть нулевым из-за дублей.

Настроенный прокси проверяется через поиск и детали. Он не заменяется случайным
бесплатным прокси. Без настройки сборщик проверяет три независимых списка
(ProxyScrape, GeoNode, Proxifly), включая SOCKS5. Кандидаты проверяются с ограничением
параллельных подключений; частные адреса исключены. Каждый выбранный маршрут должен
прочитать непустой поиск и карточку с совпадающим ID.

## Как читать статус

- `last_result` — последний ответ worker, включая пропуск `not_due`.
- `last_collection_result` — последний реальный сбор; пропуск не стирает его.
- `last_success_at` обновляется только после чтения страницы источника.
- `last_source_error` и `error` сохраняют тип ошибки и HTTP-статус.
- Возврат кода 0 без прочитанных страниц считается ошибкой `NoSourcePagesRead`.

Наличие работающего процесса и зелёный общий workflow публикации не означают,
что Lalafo удалось прочитать. Сбор Telegram, очередь публикации, доля 50/50,
ручное одобрение и доступ за 499 сом на 7 дней этим изменением не меняются.
